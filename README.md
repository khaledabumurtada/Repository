# دليلي — دليل تطبيقات الذكاء الاصطناعي

موقع جاهز (HTML/CSS/JS بدون سيرفر) بعربي/إنجليزي، فيه **109 تطبيق** مصنّفة ضمن **14 تصنيف** (ذكاء اصطناعي، تصميم، صوت، تسويق، بناء تطبيقات، إلخ)، بحث فوري، ولوحة تحكم بسيطة لإضافة/تعديل/حذف التطبيقات.

## محتويات المجلد
```
index.html      → الصفحة الرئيسية (الدليل نفسه)
about.html      → صفحة "من نحن"
privacy.html    → سياسة الخصوصية (مطلوبة لقبول AdSense)
contact.html    → صفحة تواصل معنا
admin.html      → لوحة التحكم (محمية بكلمة مرور بسيطة)
data.js         → كل بيانات التطبيقات والتصنيفات (تقدر تعدّلها يدويًا كمان)
style.css       → تنسيق الموقع
script.js       → منطق البحث والفلترة وتبديل اللغة
```

## 1. كيف تشغّل الموقع محليًا للتجربة
افتح `index.html` مباشرة بالمتصفح، أو شغّل سيرفر بسيط:
```bash
python3 -m http.server 8000
```
وبعدين افتح `http://localhost:8000`.

## 2. النشر (اختر وحدة)

### أ) دومين خاص + استضافة عادية (الأفضل احترافيًا، متوافق تمامًا مع AdSense)
1. اشترِ دومين (رأيت روابط Namecheap / Hostinger بجدولك — تقدر تستخدم أي منهم).
2. ارفع كل ملفات هذا المجلد لمجلد الاستضافة (عبر FTP أو لوحة تحكم الاستضافة).
3. خلص — الموقع هيصير شغال على دومينك مباشرة.

### ب) استضافة مجانية بسيطة (GitHub Pages) — مناسب للبداية بدون تكلفة
1. أنشئ Repository جديد على GitHub وارفع الملفات.
2. من إعدادات الـ Repository → Pages → فعّل النشر من الفرع الرئيسي.
3. رح ياخذك رابط مجاني، وبعدين تقدر تربط دومينك الخاص فيه من نفس الإعدادات.

### ج) بلوجر (Blogger)
بلوجر أصلًا منصة تدوين ومو مصممة لاستضافة موقع HTML متعدد الصفحات بهالشكل (فيه صفحات وملفات منفصلة زي admin.html و data.js). الأنسب إنك تستضيف هالملفات بموقع حقيقي (خيار أ أو ب فوق) بدل بلوجر، وإذا لسا مصمم على بلوجر، ممكن تحط محتوى الصفحة الرئيسية بس كـ"صفحة" داخل بلوجر بدون لوحة التحكم والبحث الديناميكي (بيحتاج تبسيط إضافي).

## 3. ربط Google Analytics
1. أنشئ خاصية GA4 من [analytics.google.com](https://analytics.google.com) وخذ رقم القياس (شكله `G-XXXXXXXXXX`).
2. افتح `index.html` وابحث عن `G-XXXXXXXXXX` (موجود بمكانين بأول الملف) واستبدله برقمك.
3. كرر نفس الخطوة إذا حبيت تتبع صفحات `about.html` / `contact.html` (انسخ نفس كود الـ Google Analytics لهم).

## 4. ربط Google AdSense
1. قدّم طلب حساب AdSense من [adsense.google.com](https://www.google.com/adsense/) بدومينك بعد ما يصير الموقع منشور.
2. **قبل التقديم تأكد إن عندك محتوى كافي وأصلي** — صفحة "من نحن" و"سياسة الخصوصية" موجودين جاهزين بالموقع، وهذا شرط أساسي لقبول AdSense.
3. بعد القبول، خذ رقم الناشر `ca-pub-XXXXXXXXXXXXXXXX` واستبدله بكل مكان مكتوب فيه هيك بالملفات (`index.html` وبداخل بيانات الإعلانات).
4. أماكن الإعلانات جاهزة بالتصميم:
   - إعلان أفقي (Leaderboard) تحت العنوان الرئيسي.
   - إعلان مستطيل بالشريط الجانبي (Sidebar).
   - إعلان داخل قائمة التطبيقات نفسها كل 8 تطبيقات (In-feed).
5. بعد إضافة رقم الناشر ورقم كل Ad Slot من لوحة AdSense، الإعلانات رح تبلش تظهر تلقائيًا.

> ⚠️ ملاحظة مهمة: صفحة "تعدين العملات الرقمية" فيها روابط إحالة (Referral links). سياسات AdSense ما بتسمح بتشجيع النقر بمقابل مادي (Incentivized clicks) — تأكد إنك ما تعرض أي مكافأة مقابل الضغط على الإعلانات أو الروابط بموقعك.

## 5. لوحة التحكم (إضافة / تعديل / حذف تطبيق)
1. افتح `admin.html` بالمتصفح.
2. **قبل الرفع، غيّر كلمة المرور الافتراضية**: افتح `admin.html` بمحرر نصوص وابحث عن السطر:
   ```js
   const ADMIN_PASSWORD = "changeme123";
   ```
   وغيّرها لكلمة مرور خاصة فيك.
3. من اللوحة تقدر تضيف تطبيق جديد، تعدّل واحد موجود، أو تحذفه.
4. **مهم:** التعديلات بلوحة التحكم بتنحفظ بمتصفحك بس (مو على السيرفر). عشان يشوفها كل زوار الموقع:
   - اضغط زر **"تنزيل data.js المحدّث"**.
   - ارفع ملف `data.js` الجديد لمكان القديم على الاستضافة (استبدال الملف).
   - هيك كل الزوار رح يشوفوا التعديل.

هاي أبسط طريقة تناسب موقع ثابت (بدون قاعدة بيانات). إذا بالمستقبل حبيت لوحة تحكم حية تحدّث الموقع مباشرة لكل الزوار بدون رفع ملف يدويًا، هاد بده قاعدة بيانات وسيرفر خلفي (Backend) — ممكن نبنيه لاحقًا إذا حبيت (مثلاً بـ Firebase أو أي سيرفر بسيط).

## 6. تعديل التصنيفات
كل تصنيف موجود بأول `data.js` بمتغير `CATEGORIES`، فيه: الاسم بالعربي، بالإنجليزي، وأيقونة (إيموجي). تقدر تضيف تصنيف جديد أو تغيّر أيقونة موجودة مباشرة من هناك.

## 7. ملاحظات على الروابط المستوردة من ملفك
- شلت من الروابط أي أكواد تتبّع أو "tokens" شخصية كانت موجودة بأصل بعض الروابط (زي `mcp_token`, `gclid`, `fbclid`) وخليت الرابط الأساسي بس — لأن هاي الأكواد مرتبطة بجلستك الشخصية ونشرها عالعلن مو آمن.
- شلت رابط تسجيل دخول جوجل الشخصي (`accounts.google.com/...`) لأنه كان رابط دخول لحسابك مو أداة عامة.
- الأوصاف اللي كتبتها للتطبيقات عامة ومختصرة — لو في تطبيق الوصف مو دقيق 100%، عدّله بسهولة من `admin.html` أو مباشرة بـ `data.js`.
